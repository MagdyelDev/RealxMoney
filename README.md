### Conversor de Moedas

Aplicativo desenvolvido com React Native e Expo que permite realizar conversões entre diferentes moedas de forma rápida e prática. O sistema utiliza dados atualizados por uma API para apresentar as cotações e calcular os valores conforme a moeda escolhida.

### Funcionalidades

* Conversão de valores entre diferentes moedas
* Cotação atualizada através de API
* Escolha das moedas para conversão
* Opção para trocar a moeda de origem e destino
* Interface simples, moderna e adaptável a diferentes telas
* Resultado da conversão de forma rápida
